# inception


**1. Docker**
Platform for creating and running containers.

**2. Container**
A running isolated environment/process for an application.

**3. Image**
The blueprint used to create containers.

**4. Dockerfile**
Instructions for building an image.

**5. Docker Compose**
Tool for defining and managing multiple containers together.

**6. Network**
Allows containers to communicate.

**7. Volume**
Keeps important data persistent outside the container's writable layer.
